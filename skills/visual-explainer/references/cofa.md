# COFA용 HTML 생성 프로필

## 등록하면 바로 요청할 수 있는가?

현재 클라이언트가 이 Skill 폴더를 실제로 읽고, 프로젝트 파일·출력 폴더와 Node.js 실행에 접근할 수 있으면 자연어 요청으로 `.src.html`과 렌더된 `.html`을 만들 수 있다. 별도 모델 API 키나 MCP 연결은 기본 HTML 생성의 필수 조건이 아니다. 등록은 자동 생성 자체가 아니라 에이전트가 참고할 지침과 리소스를 제공한다.

폴더 전체를 추가한다. `SKILL.md` 하나만 복사하면 `references/`, `kit/`, `plan/`과 번들 리소스가 빠져 렌더링이 실패할 수 있다. Codex에서 일반적으로 쓰는 Skill 등록은 다음 턴이나 새 세션에서 확인한다. COFA 설치본의 등록·실행·HTML 미리보기는 그 환경에서 별도로 확인한다.

## 이 프로필의 실행 방법

1. 사용자가 요청한 코드 범위와 실제 파일을 읽고 근거를 정리한다. 정적 코드에서 확인한 경로, 실제 실행에서 확인한 경로, 미확인 연결을 구분한다.
2. `style-guide.md`, `diagrams.md`, 필요하면 `motion.md`, 태그를 쓰면 `kit.md`를 읽고 기본 kit HTML을 작성한다. 특정 그림에 필요하지 않은 전체 참조는 읽지 않는다.
3. 출력은 제공 작업 공간의 허용된 폴더에 작성한다. 실제 파일·함수·행, 검사 결과와 미확인 항목을 표시한다. 원본의 홈 디렉터리 기본 출력보다 사용자·과제 경로를 우선한다.
4. 다음 명령의 경로를 실제 환경에 맞춰 실행한다.

```text
node <이 Skill 경로>/kit/render-cofa.mjs <출력 폴더>/flow.src.html -o <출력 폴더>/flow.html --root <실제 프로젝트 경로>
```

이 래퍼는 별도 npm 설치 없이 번들 렌더러를 사용한다. 자동 브라우저 실행·스크린샷 검사를 수행하지 않으며, 폰트 외부 연결을 제거하고 외부 리소스 로딩을 제한한다. 추가 CDN·원격 폰트·외부 이미지·API에 의존하는 페이지를 작성하지 않는다. 로컬 코드 모듈을 실행하는 flow-model 가져오기는 비활성화돼 있으므로 일반 SVG 또는 선언형 `<ve-flow>`를 사용한다. 전문 plan 전용 마크업·PPTX·영상 기능은 이 기본 래퍼의 범위가 아니다.

기존 출력은 덮어쓰지 않는다. 동일 산출물을 갱신하라는 요청이 있을 때만 `--force`를 사용한다. 원본 일반 렌더러 `kit/render.mjs`는 `--no-check` 없이 브라우저 검사를 할 수 있고 `--open`은 브라우저를 열 수 있으므로, 이 프로필에서는 래퍼를 기본으로 한다. upstream의 일반 delivery 절차가 이 경계를 덮어쓰지 않는다.

## 사용자가 볼 결과

HTML 파일은 수동으로 열거나 플랫폼이 허용하는 내부 미리보기에서 확인한다. DOM 클릭·키보드 단계 이동·재생 같은 페이지 자체의 인터랙션과, 에이전트가 브라우저를 자동 조작하는 검사를 구분한다. 후자의 시험 허용 여부를 추정하지 않는다.

슬라이더와 노드 강조가 움직인다는 사실은 실제 시스템을 추적했다는 증거가 아니다. 애니메이션은 읽은 코드와 명시한 관측을 설명하는 모델이다. 실행해 보지 않은 요청·Docker·DB 동작은 실행 검증 완료로 표시하지 않는다.

`cofa-architecture-tour`가 함께 있으면 코드 근거·계획/구현/검증 상태의 기준을 그 Skill과 맞춘다. 두 개의 서로 다른 아키텍처를 만들지 말고 하나의 사실 목록을 표현한다. Node가 없거나 렌더링이 막히면 원인을 기록하고, 제공되는 Python 기반 `cofa-architecture-tour` 렌더러나 Markdown 설명으로 진행한다.

## 요청 예시

```text
visual-explainer를 적용하고 COFA 프로필을 따라줘.
현재 구현 코드에서 대표 요청 한 건의 흐름을 실제 파일·함수 근거로 추적해줘.
입력 → 요청 처리 → 검증 → 업무 로직 → 데이터 조회·저장 → 응답·표시를
단계별로 넘겨 볼 수 있는 HTML로 만들어줘. 없는 계층은 추가하지 마.
계획·정적 코드 확인·실행 검증·미확인 연결을 구분해줘.
제공 작업 공간의 출력 폴더를 사용하고 브라우저 자동 실행 없이 경로를 알려줘.
```

실제 과제의 결과물은 공개 저장소에 올리지 않는다. AI 금지 서술형 단계에서는 이 Skill을 호출하지 않는다.
