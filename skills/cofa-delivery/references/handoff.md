# 맥락 유지와 인계

맥락을 줄이기 전에는 목표·결정·현재 실패·다음 작업을 파일로 정리한다. 새로운 세션이 지원되는지 확인하고, 지원되지 않으면 같은 세션에서 짧은 요약으로 진행한다. 전환 자체를 목적으로 새 세션을 만들지 않는다.

## 인계할 내용

- 과제 목표와 기준 명세 위치.
- 완료한 요구사항과 실제 검증 결과.
- 중요한 파일과 데이터 흐름.
- 결정 이유와 변경하면 안 되는 계약.
- 현재 실패의 재현 조건과 확인한 원인.
- 실행 중인 서비스·포트와 필요한 명령.
- 미검증 항목, 남은 시간과 다음 우선 작업.

원문 로그 전체를 반복하지 말고 근거 파일이나 관련 출력 위치를 남긴다. 실패 이력을 지워 성공처럼 보이게 만들지 않는다. 키·토큰·개인정보는 기록하지 않는다.

다음 세션에는 인계 문서와 기존 지침을 읽고 실제 코드·상태와 일치하는지 확인한 뒤 이어가도록 요청한다. 종료된 서버·옛 테스트 결과를 현재 상태로 가정하지 않는다.

필요하면 [작업 기록 템플릿](../assets/worklog.md)과 [인계 템플릿](../assets/handoff.md)을 사용한다. 필수 제출 파일명과 기존 문서가 우선이다.
