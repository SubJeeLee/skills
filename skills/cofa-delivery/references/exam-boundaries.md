# 시험 안내 요약과 미확인 사항

기준일: 2026-10-30. 참가자가 제공한 2026 SK하이닉스 2차 예선 안내 3종을 요약했다. 공식 원문을 대체하지 않으며 개정 여부는 별도로 확인해야 한다. 개인 배포 문서는 이 저장소에 재배포하지 않는다.

## 반드시 미확인으로 유지할 항목

- 본인이 시험 전에 작성해 public으로 게시한 개인 프롬프트·템플릿의 반입 허용.
- 후속 서술형에서 제출한 docs·코드를 열람할 수 있는지와 접근 방법.
- Playwright Test 실행과 Playwright MCP·CLI 브라우저 조작 각각의 허용 여부.
- COFA Codex의 실제 버전, Skill·Plugin·서브에이전트 지원 및 설치 권한.
- 제공 모델의 실제 사용 한도와 동시 세션 제한.

불명확한 권한은 경과 시간이나 응답 부재로 승인됐다고 보지 않는다. 허가가 필요한 기능은 확인 전 사용하지 않고 허용된 대안으로 진행한다.

## 확인 질문 예시

1. 개인이 사전 작성한 범용 작업 지침을 공개 GitHub에 게시하고 제공 Codex로 읽어도 되나요?
2. 과제 앱에 대한 Playwright Test와 AI의 Playwright MCP·CLI 조작이 각각 허용되나요?
3. 후속 서술형 중 제출한 README·docs·코드를 AI 없이 열람해도 되나요?
4. 제공 Codex의 사용량 상한과 동시 세션 제한은 무엇인가요?

## 장비와 장애 대응

- 단일 모니터, 컴퓨터 웹캠, 충전 중인 Proctor 휴대폰·거치대와 실물 신분증을 준비한다.
- 외장 키보드는 안내상 유선 1개까지 허용, 블루투스 키보드는 불허다.
- 신분증은 종류별 가림 범위를 공식 안내대로 준비한다. 신분증·초대 링크를 저장소에 기록하지 않는다.
- 신분증·안경 확인은 녹화 시작 후 휴대폰 Proctor 카메라로 안내된 순서에 따라 진행한다.
- 사용법·제출 절차는 Cofa Helper, 업무 맥락은 실무자 에이전트, 반복 오류·감독 장애는 문제 신고를 이용한다.
- 장애 시 발생 시각·단계·오류·직전 동작을 기록한다. 신고나 재접속이 타이머 정지를 뜻하지 않는다.
