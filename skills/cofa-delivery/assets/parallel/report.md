# 작업 결과

- 작업 ID·회차:
- 요청 경로:
- 담당 세션 별칭과 실제 세션 ID(제공될 때만):
- 결과: completed / blocked / failed 중 실제 상태

- 작업 중 입력 변경: 없음 / 있음 / 확인 불가

## 변경 파일

실제로 수정한 파일을 모두 열거한다. 제품 코드를 수정하지 않았다면 명시한다. 요청 범위 밖 변경은 수행하지 말고 필요성만 보고한다.

## 실제 검사

| 명령·조건 | 실행 여부 | 실제 결과·로그 위치 | 미검증 범위 |
| --- | --- | --- | --- |

정적 코드 확인, 실행한 검사, 사람이 확인한 동작을 구분한다. 테스트나 브라우저·Docker가 실행되지 않았다면 성공으로 쓰지 않는다.

## 메인에 전달할 내용

- 완료 조건 충족 여부와 한계:
- 계약 변경 또는 재질문이 필요한 항목:
- 충돌 가능성·변경된 입력·재검토할 범위:
- 통합 후 다시 실행할 검사:

이 보고서는 제안·결과이며 통합 승인이 아니다. 메인이 원문·diff·검사 근거로 접수한다.
