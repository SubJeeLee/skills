# 문제 정의 검토 요청

이 문서는 메인이 작성하고 검토 담당은 읽는다. 경로·버전·해시는 실제로 확인한 값만 쓴다.

- 작업 ID·검토 회차:
- 요청 목적과 현재 남은 시간:
- 실행 방식: 별도 Bash CLI 세션 / 실제 네이티브 서브에이전트 / 순차 검토
- 공통 작업 공간과 확인 방법:
- 원문 README·요구사항 경로:
- 데이터 설명·샘플 경로:
- 실제 담당자 답변 기록 경로:
- 기준 명세·가정·인수 조건 경로:
- 대상 버전·스냅샷 또는 시작 내용 해시:
- 특히 대조할 요구사항 ID:
- 검토 담당이 읽을 수 없는 입력과 이유:
- 검토 담당이 작성할 보고서의 단독 경로:
- 변경 금지 범위: 제품 코드, 기준 명세와 공유 설정
- 반환할 내용: 판정, 근거 있는 발견, 우선순위, 구현 영향과 최소 조치
- 입력이 변경됐을 때 처리 방법:

보고서 회수 후 메인이 원문을 확인해 기준 명세에 반영한다. 이 요청에 적었다는 사실만으로 다른 세션이 자동 시작되거나 메시지가 전달되지는 않는다.
